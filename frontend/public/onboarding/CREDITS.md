## How to swap an image

1. Drop a new JPG/PNG into this folder with the same `slide-N.jpg` name
2. Or change the `image` field in `frontend/src/pages/Onboarding.tsx`
3. Redeploy: `git add . && git commit -m "swap onboarding photo" && git push`

## Recommended photo specs

- **Aspect ratio**: 4:5 portrait (e.g. 1200 × 1500)
- **Format**: JPEG (smaller) or WebP (smaller still)
- **Size**: ~150–300 KB after compression
- **Theme**: dark, moody, gold-toned — upscale, romantic, real
